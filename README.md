# Dymail

Windows 桌面邮件客户端，把多个邮箱聚合在同一界面里统一管理。

## 功能

- 多账户：Gmail、Outlook/Hotmail、QQ、163/126、阿里、新浪、企业邮箱与自定义 IMAP/SMTP
- 三栏固定布局（侧栏 / 列表 / 正文），非内容区域不需要滚动
- 列表悬停出现复选框，可多选（Shift 连选，标题栏一键全选）后批量加星标、取消星标、已读、未读、归档、删除；删除在「已删除」文件夹内会二次确认后永久删除
- 批量操作按「账户 + 文件夹」合并成一条 IMAP 命令（uid 打包成 sequence set），不同账户并行下发，几十封邮件也是一次往返，未读数一次性更新而不是逐封递减
- 「已删除」里可单封或批量还原到该账户收件箱；应用每天自动彻底删除停留超过设定天数（默认 30 天，可在设置里改成 15/60/90 天或关闭）的已删除邮件，清理结果用一条提示汇总
- 侧栏「星标」聚合所有账户收件箱里加星的邮件，「归档」聚合各账户的归档文件夹（账户原本没有归档文件夹时，第一次归档会在服务器上建一个「归档」），「联系人」管理本地常用地址
- 写信时点收件人 / 抄送 / 密送行尾的联系人图标可搜索并插入常用地址，也可以直接手填临时地址
- 亮色、暗色、跟随系统；暗色下正文按邮件原有配色整体反相，保留作者定义的对比度
- 邮件正文在沙箱 iframe 中渲染，先经 DOM 清洗（脚本、表单、事件属性、危险 URL 全部移除），远程图片可按需在设置里放行或阻止
- 阅读页可一键把英文正文翻译成中文，再点一次还原原文；默认走无需注册的 MyMemory 免费服务（额度较小，超长正文只翻前面部分），在设置里填 DeepL 密钥则优先用 DeepL，失败自动回落到免费服务
- 新邮件桌面通知，关闭窗口默认最小化到托盘继续收信
- 检查更新走 GitHub Releases，发现新版可下载或忽略该版本
- 账户密码通过 Electron safeStorage（Windows 数据保护 API）加密保存；系统加密不可用时直接拒绝保存，不会写明文
- Gmail 表单按 Google 现状指引：密码框标注为「应用专用密码」，粘贴时自动去掉分组空格，登录被拒时给出开启两步验证后获取应用专用密码的说明与帮助链接
