# Dymail

Windows 桌面邮件客户端，把 Gmail、Outlook、QQ、163 等多个邮箱聚合在一个界面里统一管理。

## 功能

- 多账户：Gmail、Outlook/Hotmail、QQ、163/126、阿里、新浪、企业邮箱与自定义 IMAP/SMTP
- Gmail 与 Outlook 支持 OAuth 授权登录，在系统浏览器完成授权，令牌不进入界面层
- 三栏固定布局（侧栏 / 列表 / 正文），非内容区域不需要滚动
- 列表支持多选（Shift 连选、标题栏全选），批量加星标、已读、归档、删除；「已删除」内可还原，并按设定天数自动清理
- 批量操作按账户与文件夹合并成一条 IMAP 命令，几十封邮件也只发一次请求
- 「星标」「归档」「联系人」跨账户聚合；账户没有归档文件夹时，第一次归档会自动创建
- 会话视图按主题合并来往邮件，收件箱、已发送和归档中的同一话题可一起查看
- 写信支持定时发送；到点后台自动发出，失败会保留在「定时发送」并自动重试
- 附件支持拖入写信页、显示大小与总容量，阅读页可一键保存整封邮件的全部附件
- 过滤器按发件人、主题或收件人自动标已读、加星、归档或删除；黑名单邮件自动移入已删除
- 邮件正文在沙箱 iframe 中渲染并清洗脚本与危险链接，远程图片可放行或阻止
- 阅读页可一键把英文正文翻译成中文：默认用免费的 MyMemory，填了 DeepL 密钥则优先走 DeepL
- 新邮件桌面通知；关闭窗口默认最小化到托盘继续收信
- 侧栏显示每个账户的连接状态，某个账户掉线或授权失效时可单独重试，不影响其他账户
- 应用内检查并下载新版本，安装版静默升级，便携版退出后自动启动新版本
- 账户密码通过 Windows 数据保护 API 加密保存，系统加密不可用时拒绝保存明文

## 下载

在 [Releases](https://github.com/Aura1n/dymail/releases) 下载：

- `Dymail-Setup-<version>.exe`：安装版，带开始菜单与桌面快捷方式
- `Dymail-<version>.exe`：单文件便携版，直接运行

## 说明

- 仅支持 64 位 Windows 10 / 11
- 部分 Microsoft 365 租户关闭了 IMAP，OAuth 授权成功也无法收信
- 便携版自动更新会下载新版本并在退出后启动，但不会删除旧文件
