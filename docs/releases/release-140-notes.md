## 1.4.0

- 新增 Gmail 与 Outlook 的 OAuth2 授权登录：系统浏览器授权、本机回环接收回调、令牌加密保存并在过期前自动刷新
- 新增应用内自动更新：检查 GitHub Releases、下载安装包并校验 sha256；安装版静默升级并重启，便携版退出后启动新版本
- 侧栏新增账户连接状态（已连接 / 正在连接 / 离线重试 / 失败），失败账户可单独重试，不影响其他账户收发信
- 账户密码与 OAuth 令牌继续通过 Windows 数据保护 API 加密保存
- 构建与测试脚本整理为 npm 命令

## 说明

- OAuth 登录需要在运行环境中配置 `DYMAIL_GOOGLE_CLIENT_ID`、`DYMAIL_MICROSOFT_CLIENT_ID` 等客户端 ID；未配置时按钮会提示缺少配置，密码 / 应用专用密码登录不受影响
- 应用内自动更新从 1.4.0 起生效，1.3.3 及更早版本需要手动下载本版本
- 安装包未签名，首次运行可能出现「未知发布者」提示
