## Dymail for Android 0.1.0

手机版首次发布：Capacitor 外壳里跑一个 Node 核心，与桌面版共用同一套邮件逻辑。

- 多账户 IMAP/SMTP 收发、星标、归档、草稿、已删除还原
- 会话视图、仅看未读、左右滑动、长按多选、下拉刷新、搜索
- 阅读页沙箱渲染正文、远程图片开关、附件保存、一键翻译成中文、屏蔽发件人
- 写信支持附件、定时发送、联系人联想、草稿自动保存
- 规则 / 过滤器与黑名单、联系人、签名、深浅色主题
- 后台收信：前台服务常驻通知 + 定时兜底检查；规则或黑名单命中的邮件不弹通知
- 应用内检测新版本（只认本仓库带 `.apk` 的发布）

## 说明

- 仅支持 64 位 ARM（`arm64-v8a`）设备，Android 7.0（API 24）及以上
- 安装包自签名，未上架任何商店：首次安装需要允许「安装未知应用」
- Gmail / Outlook 的网页授权登录暂不可用，请用应用专用密码或授权码
- 后台收信依赖一条常驻通知；国产系统需要在系统设置里允许自启动与后台运行
- 系统结束进程后不会自动恢复，打开一次应用即可继续；被结束时应用会尽量提示
- 账户密码加密保存，但密钥仍在应用私有目录，不在 Android Keystore
- 内置的 Node.js 运行时基于已停止维护的 Node 18（上游作者建议只做自用侧载），因此本版本定位是自用与尝鲜，不作为商店发行版
