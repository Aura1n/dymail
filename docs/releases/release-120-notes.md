## 1.2.0

- 邮件列表支持多选：悬停出现复选框、Shift 连选、标题栏一键全选，可批量加星标、取消星标、已读、未读、归档、删除
- 批量操作按「账户 + 文件夹」合并成一条 IMAP 命令、跨账户并行下发，几十封邮件一次往返完成，未读数一次性刷新不再逐封递减
- 侧栏新增「星标」聚合所有账户收件箱里加星的邮件，「归档」聚合各账户的归档文件夹
- 新增本地联系人管理，写信时点收件人 / 抄送 / 密送行尾的图标可搜索并插入常用地址，也可以临时手填
- 阅读页可一键把英文正文翻译成中文，再点一次还原原文；默认使用无需注册的免费翻译服务，可在设置里填 DeepL 密钥（用系统加密保存，DeepL 失败自动回落到免费服务）
- 修正暗色模式下写信发件人下拉框白底、复选框与头像圆心对齐等问题，常规设置收进一屏无需下拉
