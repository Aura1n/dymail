## 1.3.2

- 常规设置新增「开机自启动」开关：开关显示的是 Windows 启动项的实际状态，只有和系统不一致时保存才会写入；开发模式下运行（`npx electron .`）不会修改启动项，请用安装版或便携版
- 设置→更新里的「GitHub 仓库」由可输入的文本框改成指向仓库主页的链接，点击用默认浏览器打开；仓库值不是 `owner/repo` 格式时不显示链接
- 设置窗口高度改为 640px，账户 / 常规 / 外观 / 更新四个标签页都不需要滚动
- 演示模式的版本号改为透传真实版本，不再写死
