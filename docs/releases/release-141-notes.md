## 1.4.1

- 联系人从设置弹窗改为主界面视图：支持搜索、新建、编辑、删除，并可从中直接写信
- 新增定时发送：写信页可选择发送时间，左侧栏集中查看、编辑、取消或立即发送；失败会保留并自动重试
- 附件管理增强：写信页支持拖入文件并显示数量与总大小，阅读页可一键保存全部附件
- 新增会话聚合视图：按账户与主题合并来往邮件，自动识别 Re、Fwd、回复、转发等前缀，阅读区按时间排列会话邮件
- 新增规则与黑名单：按发件人、主题或收件人自动标已读、加星、归档或移入已删除；黑名单邮件自动标已读并移入已删除

## 说明

- 定时发送需要应用保持运行；关闭主窗口后应用仍在托盘运行，到点会后台发送；彻底退出后不会发送，下次启动会补发已到期邮件
- 规则和黑名单只对保存之后收到的新邮件生效，不会追溯移动已有邮件
- 会话视图按账户隔离，不同账户的相同主题不会串在一起
- 安装包未签名，首次运行可能出现「未知发布者」提示
